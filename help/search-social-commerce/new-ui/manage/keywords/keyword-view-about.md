# (Nuova interfaccia) Informazioni sulla visualizzazione [!UICONTROL Keywords]

*funzionalità Beta*

La visualizzazione [!UICONTROL Manage] > [!UICONTROL Keywords] include due schede:

* Nella scheda [!UICONTROL Keywords] sono elencate tutte le parole chiave nella visualizzazione filtrata per l&#39;account dell&#39;inserzionista selezionato.

* Nella scheda [!UICONTROL Negatives] sono elencate tutte le parole chiave negative nella visualizzazione filtrata per l&#39;account dell&#39;inserzionista selezionato.

## Azioni disponibili

* [Assegnare vincoli alle parole chiave e annullare l&#39;assegnazione di vincoli alle parole chiave](/help/search-social-commerce/new-ui/manage/keywords/keyword-constraint-assignments-manage.md)

* [Assegna classificazioni etichette](/help/search-social-commerce/new-ui/set-up/label-classifications-manage.md) alle parole chiave

>
>* [Gestisci assegnazioni vincoli per parole chiave](/help/search-social-commerce/new-ui/manage/keywords/keyword-constraint-assignments-manage.md)
