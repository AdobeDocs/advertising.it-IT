# Paragrafo utilizzato nell’introduzione ad alcuni file di appendice dei bulksheet

Ogni bulksheet deve includere i campi intestazione e i campi dati corrispondenti necessari per le [operazioni specifiche che si desidera eseguire](/help/search-social-commerce/campaign-management/bulksheets/bulksheet-data-formats/bulksheet-operations.md) (ad esempio la creazione di un annuncio). Quando un campo non è obbligatorio, puoi ometterlo dall’intestazione e dalle righe di dati. Tutte le colonne personalizzate vengono eliminate quando carichi il file bulksheet.

Di seguito sono riportati i campi di intestazione disponibili e le descrizioni dei campi di dati corrispondenti, nonché ulteriori informazioni necessarie per aggiungere, modificare o eliminare dati.
